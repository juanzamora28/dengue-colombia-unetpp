# Dengue Colombia U-Net++

This repository contains the data organization, source code, utilities, and results used for U-Net++-based spatiotemporal dengue risk mapping in Colombia.

## Associated manuscript

This repository contains the computational materials used in the associated scientific manuscript.

The exact version used for the manuscript is identified as release `v1.0.0` and is permanently archived in Zenodo.

## Repository contents

* `department_binary.py`: department-level modelling and evaluation pipeline.
* `global_binary.py`: global modelling and evaluation pipeline.
* `2007-2019/`: data and results organized for the 2007–2019 study period.
* `2016-2019/`: data and results organized for the 2016–2019 study period.
* `2018-2019/`: data and results organized for the 2018–2019 study period.
* `Shape/`: spatial boundary and geographic files.
* `Utilidades/`: supporting utilities and data-processing scripts.
